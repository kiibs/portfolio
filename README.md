# EMMA — Graphic Designer Portfolio

A creative, animated bilingual portfolio template for a recently graduated graphic designer.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP 3 + ScrollTrigger + ScrollToPlugin
- Google Fonts (Space Grotesk + DM Mono)
- No build step / no framework

## Run locally

Open `index.html` with VS Code Live Server, or simply open it in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload everything in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save.

The project uses relative paths and CDN-hosted GSAP, so it works as a static GitHub Pages site.

## Customize

- Replace the fictional project content in `index.html` and `script.js`.
- Edit colors and typography in `style.css`.
- Replace `hello@EMMA.design` with your real email.
- Add your real social links in the contact section.
- Project visuals are CSS-generated posters, so there are no missing image assets.

## Included interactions

- First-visit animated loader (session-only)
- Light / dark theme with persistence
- English / Spanish toggle with persistence
- Magnetic cursor
- Hero kinetic typography
- Rotating SVG orbit
- ScrollTrigger reveals and parallax
- Project detail modal
- Full-screen mobile/desktop navigation
- Reduced-motion media query
- Responsive layout
